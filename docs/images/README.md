# Screenshots

These come from the demo mode, so no real device names appear. To recreate them, run the demo tour and capture each window it publishes in the app container:

```sh
open -n build/DerivedData/Build/Products/Debug/QuietDeck.app --args --demo --tour -AppleLanguages '(en)'
```

For a manual look, leave out `--tour`. The panel shots show the panel in a plain window, because it can't be opened from code.
