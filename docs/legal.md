## Interoperability

QuietDeck exists so that people can use headphones they own from their own computers. It talks to paired devices over standard Bluetooth.

- It contains no code, firmware, assets or keys from any manufacturer.
- It doesn't bypass, emulate or extract any authentication mechanism or key. Functions that need manufacturer authentication aren't used, and the Protocol Console refuses them.
- It's an independent implementation. The projects named in the README served as references for protocol behavior, and behavior was confirmed by observing the app's own communication with the device.
